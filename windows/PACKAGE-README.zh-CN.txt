Doubao Skin Windows 安装说明
=============================

1. 先右键 ZIP，选择“全部解压”。不要直接在 ZIP 预览窗口里运行文件。
2. 打开解压后的“Doubao Skin”文件夹。
3. 双击“Install Doubao Skin.cmd”。
4. 安装成功后，从桌面或开始菜单打开“Doubao Skin”。
5. 选择主题背景缩略图，然后点“启用”或“切换到”。
6. 有聊天内容时，可拖动“对话页蒙版透明度”调整阅读遮罩：
   0% 完全遮挡，100% 完全透明，默认 40%。
7. 可在窗口顶部勾选或取消“开机自动启动”。勾选后，下次登录会显示
   管理窗口和任务栏按钮；取消后不会立刻退出当前管理器。

点“停用并恢复”后如果想重新使用皮肤，请重新选择主题并点绿色“启用”按钮；
“打开豆包”只负责启动，不会替代“启用”。应用失败时程序会弹窗显示原因。

点管理器窗口右上角 X 只会隐藏到系统托盘。只有托盘菜单中的
“退出管理器”才会结束管理器。托盘图标可能位于任务栏右侧的 ^ 隐藏区。

安装位置：
%LOCALAPPDATA%\Programs\Doubao Skin\

主题库：
%LOCALAPPDATA%\DoubaoSkin\themes\

添加主题时，在管理器点“打开主题库”，把包含 theme.json 和背景图片的
完整主题文件夹粘贴进去，再点“刷新”。

安装后会一次性加入 MBTI 男生、女生各 16 套主题和“陆思源 · 暖阳书房”，
默认是“INFP · 调停者男孩”。以后删除主题文件夹再点“刷新”，软件不会自动补回。
每个主题的 theme.json 必须使用不同的 id。

如果双击安装脚本被系统拦截，可在当前文件夹打开 PowerShell，运行：

powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Install Doubao Skin.ps1"

本工具不会修改、解包或重签官方豆包。官方豆包升级后若身份或页面结构变化，
工具会停止接管并提示验证失败，而不是绕过安全检查。
